Output strategy · Internal

The engine is built. What changes is how it speaks.

Caspr already produces analyst-grade analysis. We are not building a second engine per segment — we are composing what exists into the register each buyer already recognises.

Every buyer received the same document.

The analysis was right; the register was generic. A PE associate and a category manager read the same paragraph, and neither felt it had been written for them.

This was never a capability gap.

The engine already does the work. What was missing sits after it — the layer deciding how a finding is said: which vocabulary, which number leads, where the deliverable stops. That is presentation, not intelligence.

The model

One engine. Four layers, composed at generation.

  • VoiceConstant. Conclusions not descriptions, numbers first, no hedging — identical in every output.
  • TypeWhat the deliverable is. Market Research · Business Case · Investment & Deal · Academic — each with its own questions, and its ceiling.
  • RegisterWho is reading. Ten ICP profiles, resolved from the account — never asked per report.
  • SurfaceHow it renders. PDF, deck or working data — one report state, drawn three ways.

Change one and the output changes. Change none and nothing forks.

An investor sees an IC Memo. A founder sees a pitch deck. Same engine, same tier, same analysis — in the words each already uses.

There is no second engine, and there will not be one.

No per-segment pipeline, no forked build. Adding an ICP is a profile, not a project; a new deliverable type is a file, not a release. Eight segments × three tiers × six formats is a maintenance liability, not a roadmap.

A discount reduces the price. It never reduces the scope.

An Academic Study at $40 is a full Study — same depth, same formats, same 80,000 edit credits as the $80 Study. Where we discount, we discount; we do not ship a thinner product and call it a saving.
