## 1. Concept

The metaphor is "The strategic options paper that settles the debate." A VP Strategy or Head of Corporate Planning recognises this document instantly — it is the kind of work that arrives before a board session and closes the discussion. The camera moves the way a senior analyst reads: deliberately, without hurry, with the quiet authority of someone who has already done the work. Dark background, near-silence, no narration. European banking architecture — the exterior of a Frankfurt or Amsterdam financial institution, a boardroom interior, or a trading floor at rest — grounds the cover in institutional weight. The emotional register is not excitement. It is the particular confidence that comes from having the numbers done before walking into the room.

## 4. Style Guide

### Background
`#0B0B09` — near-black with a warm undertone. Not pure black (#000000). Consistent across all shots.

### Document Presentation
- Pages displayed at approximately 75% canvas width, centred vertically and horizontally
- Drop shadow: `0px 8px 40px rgba(0,0,0,0.6)` — creates physical weight, implies paper
- No border, no frame, no device mockup (phone, laptop, browser chrome)
- Pages should read as documents, not as software screenshots

### Typography (overlays only)
- Typeface: Inter
- Sizes: 11–14pt (never larger — this is supplementary, not headline)
- Colour: #F5F2EF (warm off-white — never pure white #FFFFFF)
- Opacity: 60–80% — always slightly transparent, never fully opaque
- Weight: Regular for metadata lines; Semi Bold for end card statements only
- No drop shadow on text overlays — the background is dark enough

### Red Accent Usage
- Colour: #E8453C (Caspr red)
- Uses: the 1px TOC rule (Shot 2), the benchmark row highlight (Shot 3, 8% opacity), the framework accent bars (Shot 5, 50% opacity), the wordmark dot pulse (End Card)
- Never used as a bold graphic element — no red text, no red shapes, no red backgrounds
- Every red use should feel incidental, not decorative

### Transitions
- Cross-dissolve only, 0.3–0.5s
- The deliberate cut between Shot 2 and Shot 3 is the single exception
- No wipes, slides, zooms, 3D page turns, push transitions, or motion blur effects

### Pacing
- Shots 1–5: slow and deliberate
- Shot 6: intentionally fast — creates contrast and conveys volume
- End card: held long enough to read all three lines comfortably
- Total target: 26–28 seconds

### What to Avoid
- Cursor or mouse movements of any kind
- Browser chrome, UI elements, navigation bars, or any software interface
- Typing animations or text appearing letter-by-letter
- Loading bars, progress indicators, or skeleton screens
- Upbeat, energetic, or motivational music
- Any element that reads as a product tutorial or feature demonstration
- Zoom transitions that feel like a Keynote presentation
- Colour grading that reads as warm/aspirational
- Text that explains what the viewer is seeing

## 6. Tool Recommendation

**Tier 1 — Professional (recommended):** Adobe After Effects.
Import exported PNGs as still images. Build one composition per shot at 1920×1080, 30fps. Use opacity keyframes for cross-dissolves. The Ken Burns effect (scale + position keyframes with ease in/out) handles the slow zooms on Shot 1. Any designer with 6+ months of AE experience can execute this brief in 3–4 hours. Render to H.264 via Media Encoder. Export a separate WebM pass for web delivery.

**Tier 2 — Accessible professional:** Jitter.video (browser-based, no software install).
Import images, sequence shots with their timing controls, use built-in dissolve transitions. Jitter produces broadcast-quality MP4 output. Execution time: 4–6 hours including asset setup.

**Tier 3 — Fast:** CapCut Pro or DaVinci Resolve (free).
DaVinci Resolve: import PNGs into the timeline, set still clip duration per storyboard timings, apply Cross Dissolve transitions from the Effects Library, use Transform > Zoom for the Shot 1 scale animation. Execution time: under 2 hours.

**Note on Figma Prototype mode:** Not suitable for video production. Use it only for internal storyboard review.
