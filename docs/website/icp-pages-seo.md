## Implementation Notes

### `<title>` tag
```html
<title>{Page title above}</title>
```

### `<meta name="description">`
```html
<meta name="description" content="{Meta description above}" />
```

### Open Graph
```html
<meta property="og:title" content="{OG title above}" />
<meta property="og:description" content="{OG description above}" />
<meta property="og:url" content="{Canonical URL above}" />
<meta property="og:type" content="website" />
<meta property="og:image" content="https://caspr.ai/og/caspr-og.png" />
```

### Twitter/X card
```html
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:title" content="{OG title above}" />
<meta name="twitter:description" content="{OG description above}" />
```

### Canonical
```html
<link rel="canonical" href="{Canonical URL above}" />
```
