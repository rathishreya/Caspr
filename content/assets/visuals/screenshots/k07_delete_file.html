Deleting a file

Serves cards: K-07 · frame 1775:2 · updated 2026-08-18
1

Select file(s) with the checkbox, then choose red Delete in the toolbar — single, multiple, or Select all.

2

The confirm shows a live count (“Delete N sources?”) and offers Move to Excluded first — kept, but not used.

3

Choose Delete permanently only when you want the copy gone; deletion can't be undone.
