# Content Library — CURRENT assumptions (as of the Aug 8 build)

This is what the 113-card help/blog/social content library currently encodes. Your job: read your assigned spec docs (the LATEST truth) and report what has CHANGED, what is NEW, and what is now WRONG — so the library can be updated.

## Pricing (as currently written in the library)
- Free trial: **$100 Research Budget**, no credit card, **90-day** expiry.
- Analysis prices: **Brief $15 · Study $80 · Intelligence $300 in-budget / $399 à la carte**; Premium Data Add-on **$20–60**.
- Plans (monthly budget / usable): **Professional $200 (~$186) · Business $600 (~$558) · Enterprise $1,800 (~$1,674, 3 pooled seats)**.
- **Business** unlocks Intelligence, data upload, editing. **Enterprise** unlocks SSO, API, seats.
- Output: base set included by tier (Brief PDF·MD; Study/Intelligence PDF·PPTX·XLSX·CSV·MD); beyond base **per-output $5 (PDF/DOCX/XLSX/CSV) / $10 (PPTX) / MD free**; extra language = per-output. (Quota + top-up pack "retired".)
- Editing = a metered re-generation. Unused balance carries forward. Internal 7% platform fee — never shown to users.

## Product flow (as currently written)
- Welcome → Conversation (clarifying Qs) → Layout (editable) → Gate (confirm Tier/formats/language/style/price; Generate = total; Tier change rebuilds layout) → Generation/Theater (atomic, no pause/stop) → Working report.
- Report surfaces (switcher): **Contents** (scroll-sync TOC) · **Ask Caspr** (scoped Q&A) · **Edit** (→ new version) · **Outputs / Generate Output** (per-output pricing) · **Versions** (timeline) · **Updates** (COMING SOON). Citations = inline red dots → scoped source; full sources = report's last card.

## Data Room (as currently written — category K)
- Groups: **Included / Excluded / Connected** (Connected = Bloomberg/Refinitiv/S&P/PitchBook = COMING SOON).
- Upload PDF/XLSX/CSV/DOCX or paste a link. **Private (default) vs Public**. Move to Excluded (reversible) vs Delete (permanent, nudges to Excluded). Data upload unlocks at Business. Projects: uploads default to Excluded (scope unconfirmed).
